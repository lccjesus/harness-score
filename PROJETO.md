# Meeting Cost CLI

Aplicação mínima de linha de comando que calcula o custo total de mão de obra de uma reunião a partir do número de participantes, da duração em minutos e do custo por hora de cada participante.

## Exemplo de uso

```sh
npm start -- 5 60 100
```

Saída:

```text
Custo total da reunião: 500.00
```
